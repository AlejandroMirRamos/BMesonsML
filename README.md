# BMesonsML

XGBoost likelihood emulator for B-meson SMEFT anomalies, based on the SMEFT19 global fit of Scenario III (rotBIII).

**Reference**: [arXiv:2412.15830](https://arxiv.org/abs/2412.15830)

**Notebook**: [View on GitHub](https://github.com/alejandromirramos/bmesonsml/blob/main/notebooks/xgboost_optimized.ipynb)

---

## Overview

This repository implements a machine-learning emulator for the global SMEFT19 log-likelihood in the three-parameter space `(C₁, C₃, βq)` of Scenario III. The emulator replaces expensive SMEFT19 evaluations with an XGBoost surrogate, enabling fast generation of confidence contours and SHAP sensitivity analysis.

**Parameter space**

| Parameter | Range | Description |
|-----------|-------|-------------|
| C₁ | [−0.30, 0.00] | Wilson coefficient (neutral current) |
| C₃ | [−0.30, 0.00] | Wilson coefficient (charged current) |
| βq | [0.00, 3.20] | Quark mixing angle |

## Dataset generation

The training dataset (10 500 points) combines two components, matching the paper:

1. **Random points** — 3 000 LHS samples covering the full parameter cube
2. **Best-fit grid slices** — three 50×50 grids in the 2D planes `(C₁,C₃)`, `(C₁,βq)`, `(C₃,βq)`, with the third parameter fixed at the best-fit value

The best-fit is located automatically with `SMEFT19.ellipse.minimum` and cached in `data/rotBIII.yaml`. Dataset generation is parallelized across all available CPU cores (SMEFT19 is CPU-only).

## Quickstart

```bash
# 1. Install dependencies
pip install smeft19 flavio xgboost shap scikit-learn imbalanced-learn scipy

# 2. Open the main notebook
jupyter notebook notebooks/xgboost_optimized.ipynb

# 3. Run all cells (dataset will be generated on first run)
```

Alternatively, generate the dataset from the command line:

```bash
python scripts/generate_dataset.py          # LHS-only dataset
python scripts/fit3.py                      # best-fit + 2D grid maps
```

## Pipeline

| Step | Cell | Description |
|------|------|-------------|
| 1 | Dataset | Best-fit → random LHS + grid slices → `data/combined_rotBIII.dat` |
| 2 | Preprocessing | Filter, EDA, SMOTE (train only), KNN likelihood for synthetic points |
| 3 | Training | XGBoost with early stopping, GPU if available |
| 4 | SHAP | Beeswarm, bar, waterfall, and dependence plots |
| 5 | Prediction | `predict_point(C1, C3, bq)` with boundary penalties |

## Results

The emulator achieves r = 0.96 Pearson correlation on the validation set (Scenario III), matching the paper. The dominant feature importance follows the expected physics: C₃ (charged-current observables RD(∗)) > C₁ (neutral-current B→Kνν̄) > βq (quark mixing).
